This is a simple program to calculate the hand needed to score above 300 in Balatro's first blind.
The eventual goal is to turn this into a real physical calculator.

Planned versions in the future will probably give probabilities of getting a hand based  on a standard deck of 52 cards
with the standard 5 card discard feature in the game.

Probably will not add jokers to the calculations but maybe if you wanted to do Ante 1 jokerless I'll add a little bit more.
